# Project Statement

## Project Title:

**Advance Python Calculator**

## Problem Statement:

Basic calculators generally provide common arithmetic operations such as addition, subtraction, multiplication, and division. The purpose of this project is to develop a simple and user-friendly calculator using Python that can perform both basic and selected advanced mathematical operations.
The calculator should provide a clear menu, accept the required values from the user, perform the selected calculation, and display the result. It should also handle common errors such as invalid numeric input and division by zero.
The project is implemented using separate Python modules so that related operations are organized into different files and the program remains easy to understand and maintain.

## Scope of the Project:
The scope of the project includes developing a console-based calculator capable of performing:

* Addition
* Subtraction
* Multiplication
* Decimal division
* Floor division
* Remainder
* Power calculation
* Factorial
* GCD
* LCM

The project also includes:

* Input validation
* Division-by-zero checking
* Menu-driven program execution
* Repeated calculations
* Modular Python files
* Basic error handling

The project is intended as a Python programming project and does not include a database or permanent data storage.

## Target Users: 
The calculator is mainly intended for:

* Students learning Python programming
* Beginners practicing functions and modules
* Users who need a simple console-based calculator
* Students learning basic mathematical programming concepts

## High-Level Features:

### 1. Basic Arithmetic:
The calculator performs addition, subtraction, and multiplication.

### 2. Division Operations:
It supports decimal division, floor division, and finding the remainder.

### 3. Special Mathematical Operations:
The calculator supports power, factorial, GCD, and LCM calculations.

### 4. Input Validation:
The program checks user input and displays a validation message when an invalid number is entered.

### 5. Error Handling:
Division by zero is detected and an appropriate error message is displayed.

### 6. Modular Structure
The project is divided into multiple Python files according to the type of operation. This improves organization and maintainability.

### 7. Menu-Driven Interface
Users can select operations from a numbered menu and continue performing calculations until they choose the exit option.
